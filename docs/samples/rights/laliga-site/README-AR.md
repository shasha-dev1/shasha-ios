قائمة الموقع تضم 216 دولة وإقليمًا. استُخرجت 215 صفحة دولة بنجاح.

هذه أسماء القنوات والمنصات التي يعرضها الموقع؛ ليست إثباتًا لقناة كل مباراة أو عدد المباريات أو الحصرية أو مدة العقود. لا تُعتبر قائمة كاملة لكل دول العالم؛ الدول غير الموجودة في محدد الموقع لم تُضف من مصادر أخرى.

استُخدمت بيانات الصفحة العامة __NEXT_DATA__ > props.pageProps.broadcasters لكل دولة. حُفظت أسماء الناقلين ومعرفاتهم وحقول المصدر كما هي. لم يُستخدم مفتاح API أو حساب أو بيانات دخول.
